# holtering

Проверка холтеровской разметки: что прибор LabTech EC-12H (CardioSpy)
разметил неверно, до того как запись прочитает кардиолог. Парсер SCP-ECG,
аудит меток, эпизоды, шумовая карта, ручные правки, печатный протокол.

- Правила для людей и агентов: [AGENTS.md](AGENTS.md).
- Локальный запуск: [docs/operations/dev.md](docs/operations/dev.md).
